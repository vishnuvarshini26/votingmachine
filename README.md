🗳️ Voting Machine in Verilog

This project presents a real-time electronic voting machine designed using Verilog Hardware Description Language (HDL). It simulates a basic but functional voting system capable of handling multiple candidates, recording votes, displaying real-time results, and declaring the winner based on majority count. The design incorporates core digital logic concepts such as counters, multiplexing, and finite state machines, making it ideal for beginners and enthusiasts interested in digital electronics and FPGA-based systems.

The system can be tested using simulation tools like ModelSim, Vivado, or Quartus, and can be synthesized for implementation on an FPGA board such as Xilinx Spartan or Intel DE1. Input buttons are used to cast votes for candidates, while the vote count and results can be displayed using LEDs or 7-segment displays. A reset function allows the system to be reused for new voting sessions, and the design can be enhanced further with features like debouncing, secure ID validation, or memory-based vote storage.

This voting machine serves not only as an academic or learning project but also as a real-time product prototype suitable for school elections, technical exhibitions, or small-scale community polling events. The project demonstrates how HDL-based design can be used to develop practical and interactive hardware applications.
